# Executive UI System

## Navigation

The public workspace modules are fixed as:

1. Dashboard
2. Projects
3. Tasks
4. Calendar
5. Files
6. Team
7. Reports
8. Settings

Admin routes remain permission-gated and separate from the main daily navigation.

## Visual Direction

- Dense, quiet workspace layouts.
- No marketing-style hero screens inside the app.
- 6-8px control radii.
- Tables, filters, badges, dialogs, toasts, and panels reuse shared primitives.
- Empty, loading, error, offline, and permission states use consistent state components.

## Workflow Expectations

- Command palette remains a primary power-user workflow.
- First-run setup lives at `/onboarding`.
- Core modules should remain keyboard-friendly and avoid layout shifts.
